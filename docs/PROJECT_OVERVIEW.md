# Project overview

## Problem addressed

Agricultural insurance workflows involve geographic parcels, contract records, damage assessment, and administrative claim review. The demo illustrates how these activities can be brought together in one interface.

## Demo user journey

1. Review headline portfolio metrics on the dashboard.
2. Draw a parcel boundary on a satellite map.
3. Enter details to register an agricultural insurance contract.
4. Preview or print a contract report.
5. Review a claim in a modal with decision actions.
6. Inspect regional vegetation and drought-risk indicators.
7. View an example subscription checkout.

## What is shown vs. what still needs confirmation

**Shown:** interface flows for parcels, contracts, claims, reporting, analytics, subscription.

**Not confirmed from video alone:** satellite data processing pipeline, accuracy/validation of derived indices, automated detection or payout eligibility criteria, persistence, authentication/security controls, production payment integration, deployment environment, or performance.
