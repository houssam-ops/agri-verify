# Contributing

This repository is a public-facing demonstration of Agri-Verify. Implementation code is not yet included.

For proposed changes:

1. Open an issue describing the improvement or bug.
2. Avoid including credentials, personal information, or private geospatial records.
3. Keep documentation and screenshots aligned with demonstrated functionality.
4. When source code is added, include reproducible steps and tests with code changes.

Do not submit actual API keys, billing credentials or private customer records.
